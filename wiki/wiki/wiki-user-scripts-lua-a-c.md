## Lua Scripts (A-C)

If you want to write your own Lua scripts, see the [Lua interface documentation](https://mpv.io/manual/master/#lua-scripting).

* **[abs-screenshot](https://github.com/Thann/mpv-abs-screenshot)** — Uses Exiftool to get "Date/Time Original" and saves screenshot with actual video capture time.
* **[abstime-osd](https://github.com/whether1/mpv-abstime-osd)** — Show absolute time of playing audio/video on OSD.
* **[acompressor](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/acompressor.lua)** — Dynamic range compressor using acompressor ffmpeg filter.
* **[adevice-list](https://github.com/dyphire/mpv-scripts/blob/main/adevice-list.lua)** — Interactive audio-device list menu.
* **[afilter](https://github.com/he2a/mpv-scripts)** — Easy access to audio compressors and HRTF sofalizer.
* **[anilist-updater](https://github.com/AzuredBlue/mpv-anilist-updater)** — Automatically updates AniList at 80% completion.
* **[animeSubs_dl](https://github.com/TnTora/animeSubs_dl)** — Download Japanese subtitles for anime from jimaku/kitsunekko.
* **[aspeed.lua](https://github.com/TinosNitso/mpv-scripts)** — Multi-stereo speed randomization & tri-color clocks.
* **[audio-balance](https://github.com/wiiaboo/mpv-scripts)** — Port of mpv's balance property to FFmpeg lavfi pan filter.
* **[audio-dupe](https://gist.github.com/bitingsock/5e9714efff963c9689b0671d68f195ad)** — Runs child process to play a second audio stream.
* **[audio-file-keys](https://github.com/fbriere/mpv-scripts)** — Automatically apply key bindings when playing audio files.
* **[Audio WebDAV & Sub WebDAV](https://github.com/Kibakus/mpv-scripts)** — Auto connection of external subtitles/sound via WebDAV.
* **[autochapters](https://github.com/po5/mpv-auto-chapters)** — Automatically finds chapters for anime files.
* **[autocomplex.lua](https://github.com/TinosNitso/mpv-scripts)** — Animated accurate stereo spectrum overlay with volume bars.
* **[autocrop](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/autocrop.lua)** — Automatically crop video using lavfi's cropdetect to detect black bars.
* **[autocrop.lua](https://github.com/TinosNitso/mpv-scripts)** — Variation crops black bars off videos/images while maintaining center.
* **[autodeint](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/autodeint.lua)** — Automatically deinterlace using lavfi's idet filter.
* **[auto-keep-gui-open](https://github.com/VideoPlayerCode/mpv-tools/)** — Switches keep-open based on video/audio mode.
* **[auto-mode](https://github.com/stax76/mpv-scripts)** — Automatically switch between video, audio and image mode.
* **[autoload](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/autoload.lua)** — Auto-load playlist entries by scanning directory. **Obsolete:** mpv now has native `--autocreate-playlist`.
* **[autoload-archives](https://github.com/AndreiVernon/mpv-autoload-archives)** — Playlist support for files inside archives.
* **[autoloop](https://github.com/zc62/mpv-scripts)** — Automatically loops files under a given duration.
* **[automask.lua](https://github.com/TinosNitso/mpv-scripts)** — Applied filter chain to animated masked region with inversion.
* **[auto-save-state](https://github.com/AN3223/dotfiles)** — Periodically saves progress and cleans watch-later data on finish.
* **[autosave](https://gist.github.com/Hakkin/5489e511bd6c8068a0fc09304c9c5a82)** — Periodically saves watch-later data during playback.
* **[autoselect-forced-sub](https://github.com/pierretom/autoselect-forced-sub)** — Auto-select forced subtitles.
* **[autospeed](https://github.com/kevinlekiller/mpv_scripts)** — Adjust monitor refresh rate and video speed for 1:1 playback (*nix).
* **[autospeedwin](https://github.com/kevinlekiller/mpv_scripts)** — Same for Windows.
* **[autosub](https://github.com/davidde/mpv-autosub)** — Fully automatic subtitle downloading. Windows, Mac, Linux.
* **[autosub](https://github.com/vayan/autosub-mpv)** — Auto-download subtitles using subliminal.
* **[autosubsync](https://github.com/joaquintorres/autosubsync-mpv)** — Auto-sync subtitles using ffsubsync.
* **[betterchapters](https://gist.github.com/Hakkin/4f978a5c87c31f7fe3ae)** — Load next/previous playlist entry if no chapters in seek direction.
* **[blackout](https://github.com/sibwaf/mpv-scripts)** — Fast crossplatform boss-key.
* **[blur-edges](https://github.com/occivink/mpv-scripts#blur-edgeslua)** — Replace black bars with blurry copy of video.
* **[bookmarker-menu](https://github.com/NurioHin/mpv-bookmarker)** — Bookmarker menu to manage all bookmarks.
* **[bookmark](https://github.com/sorayuki-winter/mpv-plugin-bookmark)** — Record and resume last play in current folder.
* **[bookmarks](https://github.com/texiwustion/bookmarks)** — Add/delete/prev/next bookmarks with persistence.
* **[boss-key](https://github.com/detuur/mpv-scripts)** — Minimise and pause video at same time. Windows/Linux.
* **[boss-key-wayland](https://github.com/Man2Dev/mpv-wayland-Boss-key)** — Boss key through xdg-portals on Linux.
* **[btfs-hook](https://github.com/aitet/mpv-btfs-hook)** — Stream torrents using FUSE via btfs.
* **[btfs-stream](https://github.com/noctuid/mpv-btfs-stream)** — Simpler btfs torrent streaming (slower than webtorrent).
* **[celebi](https://github.com/po5/celebi)** — Optimized script to restore properties from past sessions.
* **[censor](https://github.com/zenyd/mpv-scripts)** — Skip over parts of videos you don't want others to view.
* **[channel mixer](https://gist.github.com/bitingsock/1e7ef04a151963b38e347a723d7e3201)** — Adjust surround channel mixing on the fly.
* **[chapter-converter](https://github.com/VimWei/mpv-config)** — Convert chapter format between YouTube and mpv.
* **[chapter-make-read](https://github.com/dyphire/mpv-scripts)** — Read namesake external chapter file; mark positions as chapters.
* **[chapters_for_mpv](https://github.com/mar04/chapters_for_mpv)** — Add, remove, edit chapters with save/load.
* **[chapterskip](https://github.com/po5/chapterskip)** — Auto-skip chapters based on title.
* **[chapter-list](https://github.com/CogentRedTester/mpv-scroll-list)** — Interactive chapter-list menu.
* **[chapters-menu](https://github.com/Seme4eg/mpv-scripts)** — List all chapters, search and choose.
* **[clipboard](https://github.com/CogentRedTester/mpv-clipboard)** — Generic clipboard interaction commands.
* **[command_palette](https://github.com/stax76/mpv-scripts)** — Searchable menu for bindings, playlist, chapters, profiles, tracks, commands, properties.
* **[control](https://github.com/oe-d/control)** — Various features mainly for controlling playback.
* **[copy to music](https://github.com/yazeed44/mpv-scripts)** — Copy media to predefined directory (Unix-like).
* **[copyTime](https://github.com/Arieleg/mpv-copyTime)** — Copy current time as HH:MM:SS.MS to clipboard.
* **[copyStuff](https://codeberg.org/raphaeltannous/mpv-copyStuff)** — Copy filename, URL, time, subtitle text, metadata to clipboard.
* **[copy-paste-URL](https://github.com/zenyd/mpv-scripts)** — Paste URLs from clipboard into mpv.
* **[countdown](https://github.com/butterw/bShaders)** — Display countdown on OSD for final seconds.
* **[cp-paste-URL](https://github.com/yassin-l/cp-paste-url)** — Linux fork of copy-paste-URL.
* **[Tcl/Tk context menu](https://gist.github.com/avih/bee746200b5712220b8bd2f230e535de)** — Configurable context-menu based on Tcl/Tk.
* **[change-screen-by-aspect-ratio](https://gist.github.com/stt/9e55ffa7f5047605b2dd8af417cf36f0)** — Change active fs-screen based on video aspect ratio.
* **[clock](https://gitlab.com/mozbugbox/mpv-script-mozbugbox)** — Show current time on screen.
* **[clipshot](https://github.com/ObserverOfTime/mpv-scripts)** — Screenshot and copy to clipboard (cross-platform).
* **[config-saver](https://github.com/Static39/mpv-scripts)** — Saves audio/subtitle track settings per folder.
* **[confluence](https://github.com/ftk/mpv-confluence)** — Open magnet links via confluence HTTP service.
* **[contact-sheet](https://github.com/occivink/mpv-gallery-view)** — Display thumbnails as contact sheet.
* **[convert_script](https://gist.github.com/Zehkul/25ea7ae77b30af959be0)** — Convert and crop videos with GUI.
* **[coverart](https://github.com/CogentRedTester/mpv-coverart)** — Auto-load external music cover art.
* **[copy-permalink](https://gist.github.com/olejorgenb/a5194d9bc183dbe0bfb02aac18fe37f9)** — Copy `mpv --time=<pos> <path>` to clipboard.
* **[copy-subtitle](https://github.com/linguisticmind/mpv-scripts)** — Copy current subtitle line to clipboard (cross-platform).
* **[copy-timestamp](https://github.com/linguisticmind/mpv-scripts)** — Copy current timecode to clipboard.
* **[createchapter](https://github.com/shinchiro/mpv-createchapter)** — Mark position as chapter, write chapters as XML.
* **[crop](https://github.com/occivink/mpv-scripts#croplua)** — Crop video by defining rectangle with cursor.
* **[cropmode](https://github.com/AN3223/dotfiles)** — Keyboard-oriented crop mode suitable for ffmpeg.
* **[curvesman](https://gitlab.com/mozbugbox/mpv-script-mozbugbox)** — Manipulate color curves filter with hotkeys.
* **[cycle-audio-device](https://gist.github.com/bitingsock/ad58ee5da560ecb922fa4a867ac0ecfd)** — Cycle through audio devices.
* **[cycle-commands](https://github.com/CogentRedTester/mpv-scripts)** — Cycle commands in input.conf with keybinds.
* **[cycle-deinterlace-pullup](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/cycle-deinterlace-pullup.lua)** — Cycle deinterlacing/pullup/off.
* **[cycle-denoise](https://gist.github.com/myfreeer/d744c445aa71c0eeb165ca39cf6c0511)** — Cycle between lavfi denoise filters.
* **[cycle_messages](https://gist.github.com/rrooij/59f57ff5f5a952e56bbb)** — Cycle custom OSD messages.
* **[cycle-through-existing](https://github.com/viniciusbm/mpv-cycle-through-existing)** — Cycle existing tracks skipping "none".
* **[cycle-video-rotate](https://github.com/VideoPlayerCode/mpv-tools/)** — Video rotation cycling through 360 degrees.
