# Upscaling

Upscaling wise the recommendation is to use `--scale=ewa_lanczossharp`, which is set by `--gpu-hq`. See the [manual](https://mpv.io/manual/stable/) for more details and more recent additions.

The following images compare different upscaling methods:

The images under `upscaling/` show comparisons of various upscaling algorithms on different source content. Experiment with different options such as `--scale=ewa_lanczossharp`, `--scale=ewa_hanning`, or `--scale=mitchell` to find what works best for your content and preferences.
