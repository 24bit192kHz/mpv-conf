## VapourSynth Scripts

* **[mvtools](https://github.com/haasn/gentoo-conf)** — Use MVTools BlockFPS for motion interpolation in realtime.
* **[nnedi3](https://github.com/haasn/gentoo-conf)** — Double resolution via NNEDI3 (too slow for realtime).
* **[flash3kyuu](https://github.com/haasn/gentoo-conf)** — Deband with flash3kyuu. **Obsolete:** mpv now has a built-in debanding shader.

## C Plugins

* **[mpv-mpris](https://github.com/hoyon/mpv-mpris)** — MPRIS2 protocol support.
* **[mpv-libunity](https://github.com/mrlotfi/mpv-libunity)** — Panel progress bar via libunity.
* **[mpv-omniGlass](https://github.com/guarapicci/mpv-omniGlass)** — Touchpad gestures.
* **[mpv-rpc](https://github.com/ryze312/mpv-rpc)** — Discord Rich Presence in Rust with cover art.
* **[shutup](https://github.com/AN3223/dotfiles)** — Set --quiet when stderr/stdout not connected to terminal.
* **[mpv-limited-autoload](https://github.com/glubsy/mpv-limited-autoload)** — Lazy auto-load limiting playlist size.
* **[kde-do-not-disturb](https://gitlab.com/smaniottonicola/kde-do-not-disturb)** — Disable notifications while mpv runs.
* **[kde-night-color](https://gitlab.com/smaniottonicola/kde-night-color)** — Disable Night Color while mpv runs.
* **[mpv_inhibit_gnome](https://github.com/Guldoman/mpv_inhibit_gnome)** — Prevent screen blanking on GNOME.
* **[mpv-menu-plugin](https://github.com/tsl0922/mpv-menu-plugin)** — Context menu, file dialog, clipboard (Windows).
* **[mpv-debug-plugin](https://github.com/tsl0922/mpv-debug-plugin)** — Debug tool for script developers.
* **[mpv-display-plugin](https://github.com/dyphire/mpv-display-plugin)** — Display properties and toggle Windows HDR.
* **[mpv-notification-osd](https://github.com/layercak3/mpv-notification-osd)** — XDG desktop notification OSD.

## Other

* **[play-with](https://github.com/grmat/play-with)** — WebExtension to open streams in external player.
