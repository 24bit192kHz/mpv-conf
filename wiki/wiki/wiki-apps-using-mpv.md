# Software That Makes Use of mpv

## Media centers / Frontends

- [Baka MPlayer](https://github.com/u8sand/Baka-MPlayer/) (C++/Qt, cross-platform)
- [celluloid](https://celluloid-player.github.io/) (GTK3, Linux/BSD) — formerly GNOME MPV
- [Kawaii-Player](https://github.com/khlam/kawaii-player) (Python, cross-platform)
- [Mpv.nvim](https://github.com/t-tomato/mpv.nvim) (Neovim plugin)
- [MPV iOS](https://github.com/mpv-easy/mpv) (iOS/tvOS)
- [MpvTagger](https://github.com/karlschriek/mpv-tagger) (shows/database)
- [SPlayer](https://github.com/ChineseDron/splayer) (Python/Qt, cross-platform)
- [xt7 player](https://github.com/kannanar/xt7-player-mpv) (Bash/GUI, Linux)
- [Videv
- [IINA](https://iina.io/) (macOS)
- [Danmaku2ASS](https://github.com/m13253/danmaku2ass) with mpv

## Daemon / CLI

- [mps-youtube](https://github.com/mps-youtube/mps-youtube) (Terminal YouTube client)
- [Synchronized Lyrics Player](https://github.com/strootje/slplayer) (Terminal)
- [mpvc](https://github.com/alberti42/mpvc) (shell script IPC client, volume/navigation)
- [mpvsock](https://github.com/psvensson/mpvsock) (socat-like tool for mpv IPC)
- [songrec](https://github.com/marin-m/SongRec) (Shazam client for Linux)
- [recut](https://github.com/erikedlund/recut) (lossless trimming)
- [ytfzf](https://github.com/pystardust/ytfzf) (YouTube search and play)
