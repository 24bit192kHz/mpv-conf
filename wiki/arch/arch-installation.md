# mpv

[mpv](https://mpv.io/) is a media player based on [MPlayer](https://wiki.archlinux.org/title/MPlayer) and the now unmaintained _mplayer2_. It supports a wide variety of video file formats, audio and video codecs, and subtitle types. A detailed (although admittedly incomplete) list of differences between _mpv_ and the aforementioned players can be found [here](https://github.com/mpv-player/mpv/blob/master/DOCS/mplayer-changes.rst).

## Installation

Install the `mpv` package.
